# 39 · 系列：四格小故事（6 篇）

- 画风线：Q 版线｜画幅：方形 1:1（1024×1024），一张图里四格｜一条提示词出一篇
- 特点：没有对白的四格漫画，只靠动作和表情讲一个小笑话。每篇一张图，四格排成两行两列。用到 36 号里的伙伴（三花猫、小麻雀、小鱼精灵）。
- 用法：上传 `f-wave.png`、06 号 Q 版设定图，以及 36 号生成的伙伴图 → 先发「系列总提示词」→ 再逐条发「单篇提示词」。

## 系列总提示词

```text
接下来我会分 6 次给你故事，每次只画一张四格漫画。所有漫画都要遵守下面的设定，直到我说「系列结束」。现在先不要画，只回复「明白」。
【角色锁定｜必须与参考图是同一个形象】二头身 Q 版小人。大大的圆头，横向椭圆的脸；黑色波波头，圆弧扇贝形齐刘海，头顶偏右后方一个圆圆的丸子发髻；深褐色大圆眼、带两点白色高光；粉色椭圆腮红；一点小鼻子和小嘴；露出一只圆耳朵。
【标志发饰】丸子发髻下方别着两片嫩绿色带尖角的小叶子，叶子下面垂着一条金黄色的小鱼吊坠。单张提示词没有另写时，发饰保持不变。
【画风】手绘贴纸风：深褐色粗描边，色块平涂，带毛毡或牛皮纸般的细颗粒质感；低饱和暖色；人物外圈一圈略不规则的米白色贴纸白边，白边外有极淡的投影；背景透明（做不到透明就用纯白）。
【禁止】不要改成写实比例；不要改变刘海形状和丸子头；不要渐变光泽、3D、金属质感；不要高饱和荧光色；除单张指定的符号外不要出现文字和水印；肢体不要被画面边缘裁掉。
【默认服装】米白底、灰色细竖条纹的和服，白色交领；单篇另写时以单篇为准。
【本系列】《四格小故事》：一张图里画四格，排成两行两列，阅读顺序是左上、右上、左下、右下。四格大小相同，格子之间留出均匀的白色间隔，每格有细细的深褐色圆角边框。四格里的小人必须是同一个形象，大小基本一致。
【画法调整】本系列不要贴纸白边，不要透明背景：每格有简单的淡色背景，只画讲故事必需的东西。可以用漫画符号（汗滴、问号、感叹号、音符、表示睡着的气泡、速度线），但不要对话框，不要任何文字和拟声字。
【伙伴】三花猫：白底，有橘色和黑色的斑块，系一条灰色细条纹的小围巾。小麻雀：茶褐色的头，白脸颊上一块黑斑，圆得像团子。小鱼精灵：她发饰上那条金黄色的小鱼，活过来时会在空中游，身后拖着小气泡。
【节奏】第一格交代情况，第二格事情发展，第三格出现转折，第四格是结果和她的表情。第四格的表情要画得最用心。
【画幅】方形 1:1。
```

## 单篇提示词

### 39-01 小鱼不见了
第一格：早晨，她对着一面小圆镜整理头发，笑眯眯的，发饰好好地别在头上。第二格：她再看镜子，发现发饰上的小鱼不见了，只剩两片叶子，头顶冒出一个大大的感叹号。第三格：她趴在地上到处找，掀开坐垫、看桌子底下，急得冒汗；画面的角落里，三花猫正背对着她，尾巴得意地翘着。第四格：猫转过身来，小鱼吊坠好好地挂在猫的耳朵上；她和猫面对面，她鼓着脸颊叉着腰，猫一脸无辜。

### 39-02 等茶凉
第一格：她端端正正地坐在小桌前，面前一杯刚泡好的茶，热气很大，她伸手碰了一下杯子，烫得缩回手。第二格：她双手托着腮，盯着茶杯等它凉，热气变小了一点，她的眼皮开始往下掉。第三格：她趴在桌上睡着了，头顶一个睡觉的气泡，茶杯已经没有热气；窗外的太阳从高处移到了很低的地方。第四格：她醒了，端起杯子喝了一口，整张脸皱成一团——茶凉透了；小麻雀站在杯沿上歪头看她。

### 39-03 整理桌面
第一格：一张很大的桌子上乱七八糟地散着许多彩色的小方块（像电脑桌面上的图标），她站在桌前，挽起袖子，一脸干劲。第二格：她抱着一摞小方块跑来跑去，把它们按颜色分成几堆，额头上有汗。第三格：桌面整整齐齐，小方块排成横平竖直的几行，她双手叉腰，闭着眼得意地笑，身后闪着小星星。第四格：三花猫从桌面正中间慢悠悠地走过去，小方块被踩得东倒西歪；她僵在原地，眼睛变成两个小点，嘴巴张成一条波浪线。

### 39-04 只睡五分钟
第一格：午后，她打了个大哈欠，抱着一只枕头，向观众竖起一只手，五根手指张开，表示「就五分钟」。第二格：她侧躺下，盖着一条小毯子，睡得很香，窗外是明亮的蓝天，三花猫蜷在她脚边。第三格：同样的构图，她睡的姿势一点没变，窗外的天变成了橙红色的晚霞，猫换了个姿势。第四格：同样的构图，窗外是深蓝色的夜空和一弯月亮；她猛地坐起来，头发乱翘，一脸惊慌，毯子滑到地上，猫被吓得跳了起来。

### 39-05 一起撑伞
第一格：下雨了，她撑着一把小纸伞走在路上，心情很好，脚下踩出小水花。第二格：路边的树枝上，一只小麻雀被淋得缩成一团，她停下来，抬头看它。第三格：她踮起脚把伞举高，罩在麻雀头顶上，麻雀开心地抖了抖羽毛；可是伞举得太偏，雨全落在了她自己身上。第四格：一排三只小麻雀整整齐齐地站在伞下，干干爽爽；她浑身湿透，头发贴在脸上，打了一个大喷嚏，脸上却在笑。

### 39-06 雪人
第一格：下雪天，她戴着毛线帽和围巾，滚着一个大雪球，鼻尖冻得通红，很开心。第二格：雪人堆好了，两颗石子当眼睛，她后退一步端详，摸着下巴，觉得还少点什么，头顶一个问号。第三格：她把自己的围巾解下来围在雪人脖子上，又把头上的叶子小鱼发饰摘下来，别在雪人的头上，满意地点头。第四格：雪人戴着围巾和发饰，看起来和她一模一样，神气地立着；她站在雪人旁边，脖子光光的，缩成一团发抖，鼻子下面挂着一条小鼻涕，但还是对着雪人竖起了大拇指。

## 扩展：自己编一篇

按这个句式写，接在系列总提示词之后发：

```text
第一格：【时间和地点】，她【正在做什么】，【表情】。第二格：【事情怎么发展】。第三格：【出现了什么意外或转折】。第四格：【结果】；她【表情，要具体】，【伙伴在做什么】。
```

好编的题材：找眼镜（其实戴在头上）、钓鱼钓上来一只鞋、给猫洗澡、晒被子遇上下雨、把盐当成糖、照镜子发现头发翘了一撮、偷吃点心被猫看见、放风筝挂在树上。

## 扩展：改成竖排长条

```text
请把刚才的第 N 篇重新排版成竖排的四格长条：四格从上到下排成一列，画幅竖版 1:3，每格的内容和画法不变，格子之间留出均匀的白色间隔。
```
