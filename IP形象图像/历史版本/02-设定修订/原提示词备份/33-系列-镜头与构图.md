# 33 · 系列：镜头与构图（12 张）

- 画风线：插画线｜画幅：按单张指定｜一条提示词出一张
- 特点：同一个场景、同一个时刻，换 12 种拍法。用来熟悉「镜头」这个变量：远近、高低、正侧、留白。以后写别的画面时，可以直接套用这里的镜头描述。
- 用法：上传基准图和设定图 → 先发「系列总提示词」→ 再逐条发「单张提示词」。

## 系列总提示词

```text
接下来我会分 12 次给你镜头描述，每次只画一张图。所有图都要遵守下面的设定，直到我说「系列结束」。现在先不要画，只回复「明白」。
【角色锁定｜必须与参考图是同一个人】二十岁左右的年轻女子。圆润的鹅蛋脸，脸颊饱满、带淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；小巧的鼻子只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后挽一个松松的低发髻。
【标志发饰】人物左耳上方（画面右侧）斜插一根柊树小枝：两三片深绿色带尖刺的叶子，枝头串着一条烤成金褐色的小鱼。单张提示词没有另写时，发饰保持不变。
【画风】日系水彩插画：细腻的深褐色线稿，淡彩平涂加轻微晕染，低饱和的大地色，看得见纸张颗粒和水渍肌理，光线柔和、没有强烈阴影，画面安静、怀旧、有文学气息。
【禁止】不要改变脸型和五官比例；不要欧美写实脸；不要浓妆和夸张睫毛；不要高饱和荧光色；不要 3D 渲染或照片质感；手指数量要正确；画面里不要出现任何文字、水印、签名、边框。
【本系列】《镜头与构图》：12 张画的是同一个场景的同一个时刻，只是相机的位置和取景不同。
【固定场景】夏天的傍晚，一栋旧木屋的廊檐。她坐在廊檐的木地板边上，双脚垂下来悬着，右手摇着淡青绿色的金鱼团扇，左手撑在身侧；身边的地板上放着一只木托盘，托盘里一杯麦茶和一碟切好的西瓜。头顶的屋檐下挂着一只玻璃风铃。面前是一个小院子：一只石水盆、一丛竹子、几盆牵牛花。天空是橙粉到淡紫的晚霞，光从画面左侧低低地照过来，影子很长。
【固定项】服装是标准的宽条纹浴衣；表情是放松的浅笑；柊枝小鱼发饰在她自己的左侧。场景里的物件和它们的相对位置每张都不变。
【画幅】按单张指定。不出现任何文字。
```

## 单张提示词

### 33-01 大远景（横版 16:9）
相机退到院子外面很远的地方：整栋木屋、屋顶、院子和屋后的树都在画面里，晚霞占画面的上半部分。她只是廊檐上一个很小的身影，但能看出条纹衣服和摇扇子的动作。用来交代地点和气氛。

### 33-02 全景（横版 3:2）
相机在院子里，正对着廊檐。她的全身和整段廊檐都在画面里，人物在画面中间偏右，左边是竹子和石水盆。人物约占画面高度的一半。最标准的交代镜头。

### 33-03 中景（竖版 3:4）
相机靠近，取她膝盖以上。能看清表情、团扇上的金鱼、身边的托盘；背景是虚化一点的纸拉门和屋内的暗处。

### 33-04 近景（竖版 3:4）
取胸口以上。她的脸占画面的三分之一，晚霞的暖光打在一侧脸颊上，另一侧是柔和的阴影；团扇的上半部分从画面下边探进来；发饰清晰可见。

### 33-05 特写 · 脸（方形 1:1）
只取脸：从额头的刘海到下巴。眼睛里映着晚霞的橙色，睫毛、脸颊上淡淡的红晕都画得细致；画面右上角露出发饰的叶子和小鱼。她正看向画面外的远处。

### 33-06 特写 · 手与团扇（方形 1:1）
不画脸。只取握着扇柄的右手和整面团扇：扇面上白色的金鱼和水纹，竹扇骨透过纸面隐约可见；背景是虚化的条纹衣料和墨绿腰带。

### 33-07 特写 · 脚（横版 3:2）
不画上半身。相机放低，只取廊檐的边缘和她垂下来的小腿与光脚，两只木屐摆在下面的踏脚石上，一只正的一只歪的；衣摆的条纹垂在画面上边。地上是长长的影子。

### 33-08 俯视（方形 1:1）
相机在她的正上方，垂直往下看：能看到头顶、脑后的低发髻和发饰、肩膀、铺开的衣摆、托盘里圆圆的杯口和三角形的西瓜、一条一条的地板。她仰起脸向上看着相机笑。

### 33-09 仰视（竖版 2:3）
相机放在院子的地面上，往上看：前景是她悬着的脚和衣摆，往上是她低头看下来的脸，再往上是屋檐、风铃和一大片晚霞。人物显得高，天空显得大。

### 33-10 背影（横版 3:2）
相机在屋子里面，从她身后往外拍：屋里是暗的，她是逆光的背影，轮廓有一圈橙色的光边，能看见腰带在背后的结和后脑的低发髻；发饰此时出现在画面左侧。她的前面是整个明亮的院子和天空，拉门的门框像画框一样框住景色。

### 33-11 前景遮挡（横版 3:2）
相机藏在院子的竹丛后面：画面左边三分之一是很近、很虚的竹叶和牵牛花，透过它们的缝隙看到廊檐上的她。她没有看相机，正低头去拿西瓜。有一点「偶然看见」的感觉。

### 33-12 大留白（横版 21:9）
超宽画幅。她和廊檐只占画面最右侧的四分之一，人物朝向画面左侧；左边四分之三全是晚霞的天空和远处一线很低的屋顶，颜色平缓过渡，没有细节。用来做横幅和超宽屏壁纸，左边可以放图标或文字。

## 镜头词表（写别的画面时直接拿来用）

| 想要的效果 | 写进提示词的话 |
|---|---|
| 交代环境 | 大远景，人物很小，只占画面高度的六分之一 |
| 人和环境各一半 | 全景，人物全身入画，占画面高度的一半 |
| 看清动作 | 中景，取膝盖以上 |
| 看清表情 | 近景，取胸口以上 |
| 强调细节 | 特写，只取某个局部，其余不入画 |
| 显得小巧、可爱 | 俯视，相机在人物斜上方 |
| 显得高大、开阔 | 仰视，相机贴近地面往上看 |
| 安静、有故事 | 背影，逆光，轮廓有光边 |
| 自然、不摆拍 | 前景有虚化的遮挡物，人物不看镜头 |
| 留地方放字或图标 | 人物靠一侧，另一侧留出大片颜色平缓的空白 |
| 稳定、正式 | 正面对称构图，人物在正中 |
| 活泼、有动感 | 画面微微倾斜，人物在对角线上 |

## 收尾

```text
系列结束。请把刚才 12 张按编号顺序排成一张分镜总览图，像电影的故事板，每格保持各自的画幅比例，用细的深褐色线框框起来，背景用米白纸色，不写字。
```
