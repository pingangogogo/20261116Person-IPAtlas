# 06 · 设定图：Q 版标准形象（单张）

- 对应：1 张图｜画风线：Q 版线｜画幅：横版 3:2（1536×1024）
- 作用：Q 版线的「三视图 + 基本表情 + 基本动作」。以后所有 Q 版系列（表情包、图标、周边）都把这张图和 `f-wave.png` 一起上传。
- 用法：上传 `f-wave.png`、`s-dev.png`、`f-tea.png` → 粘贴下面整段。

## 提示词

```text
请以我上传的贴纸图为基准，画一张 Q 版形象设定图。
【角色锁定｜必须与参考图是同一个形象】二头身 Q 版小人。大大的圆头，横向椭圆的脸；黑色波波头，圆弧扇贝形齐刘海，头顶偏右后方一个圆圆的丸子发髻；深褐色大圆眼、带两点白色高光；粉色椭圆腮红；一点小鼻子和小嘴；露出一只圆耳朵。
【标志发饰】丸子发髻下方别着两片嫩绿色带尖角的小叶子，叶子下面垂着一条金黄色的小鱼吊坠。单张提示词没有另写时，发饰保持不变。
【画风】手绘贴纸风：深褐色粗描边，色块平涂，带毛毡或牛皮纸般的细颗粒质感；低饱和暖色；人物外圈一圈略不规则的米白色贴纸白边，白边外有极淡的投影；背景透明（做不到透明就用纯白）。
【禁止】不要改成写实比例；不要改变刘海形状和丸子头；不要渐变光泽、3D、金属质感；不要高饱和荧光色；除单张指定的符号外不要出现文字和水印；肢体不要被画面边缘裁掉。
【第一排：角度】同一个 Q 版小人的全身站姿四个：正面、四分之三侧面、正侧面、背面。等高、脚底对齐。背面画清楚丸子发髻、叶子和小鱼吊坠的位置。
【第二排：表情】六个大头特写：平静（圆眼）、开心（眼睛笑成两道弯弧）、惊讶（眼睛变成两个小圆圈、嘴张圆）、生气（眉毛倒八字、鼓腮）、委屈（眼角下垂、一颗泪）、困（眼睛眯成两道横线、头顶一个小泡泡）。
【第三排：动作】六个全身小动作：挥手、双手捧着冒热气的茶杯、抱着笔记本电脑、坐着打盹、双手举高欢呼、蹲着看地上的金鱼缸。
【服装】米白底、灰色细竖条纹的和服，白色交领；手脚是简化的圆形。
【统一规格】每个小人都有自己的米白色贴纸白边；描边粗细一致；色块有细颗粒质感；整张图的底色用很浅的暖灰色（#EFE8DD），方便看清白边。不要任何文字和编号。
【画幅】横版 3:2。
```

## 验收要点

- 刘海是不是「圆弧扇贝形」（一排小半圆），丸子头是不是在头顶偏右后方。
- 发饰是不是「两片嫩绿尖叶 + 一条垂着的金黄小鱼」。
- 白边是不是每个小人各自一圈，而不是整张图一个大白边。
