# 02 · 设定图：三视图与比例（单张）

- 对应：1 张图｜画风线：插画线｜画幅：横版 3:2（1536×1024）
- 作用：让 GPT 先把「这个人从各个角度长什么样」定下来。这张图做好以后，每次新对话都和基准图一起上传。
- 用法：新开对话 → 上传修订版 02 三视图、04 发饰图；原始插画仅补充面部与画风 → 粘贴下面整段。

## 提示词

```text
请以我上传的第一张图为人物基准，画一张角色设定图（三视图）。
【角色锁定｜必须与参考图是同一个人】二十岁左右的年轻女子。圆润的鹅蛋脸，脸颊饱满、带淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；小巧的鼻子只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后挽一个松松的低发髻。人物以修订版 02 号三视图和 04 号发饰图为准，原始插画只补充面部与画风。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝：两三片深绿色带尖刺的叶子，枝头串着一条金褐色、短胖圆腹的小鱼，躯干长高比约 1.5–1.8，含短尾的总长约为鱼身高度的 2 倍；圆眼、小短尾，鱼形以修订版 04 号发饰图为准。单张提示词没有另写时，发饰保持不变。
【画风】日系水彩插画：细腻的深褐色线稿，淡彩平涂加轻微晕染，低饱和的大地色，看得见纸张颗粒和水渍肌理，光线柔和、没有强烈阴影，画面安静、怀旧、有文学气息。
【禁止】不要改变脸型和五官比例；不要欧美写实脸；不要浓妆和夸张睫毛；不要高饱和荧光色；不要 3D 渲染或照片质感；手指数量要正确；画面里不要出现任何文字、水印、签名、边框。
【画面内容】同一个人物的全身站姿，从左到右并排四个角度：正面、四分之三侧面、正侧面、背面。四个人等高、脚底在同一条水平线上，头身比例约七头身。双臂自然下垂，双脚并拢，表情平静。
【服装】暖米色与炭灰褐色相间的宽条纹浴衣，白色半襟，墨绿色暗纹腰带，腰带在背后打成文库结；赤脚穿原木色木屐、深绿色屐带。背面要画清楚发髻的形状、后颈、腰带结。
【发饰】四个角度都要能看清柊枝与小鱼的位置：始终在人物自己的左侧、耳朵上方、靠近发髻。
【附加小图】画面右上角加两个小特写：① 头部正面特写；② 发饰特写（柊叶的尖刺、枝条、小鱼的鳞片和眼睛）。画面底部加一排 8 个圆形色块，依次是：发色、肤色、腮红、浴衣浅条、浴衣深条、腰带绿、柊叶绿、小鱼金褐。
【背景】干净的暖灰米色纸面，只有淡淡的水渍肌理，没有场景；每个人物脚下一小块淡灰色投影。
【要求】四个角度必须是同一个人：脸型、发型、发饰、服装花纹完全一致；条纹的宽度和方向前后对得上。这张图允许有色块，但不要写任何文字标注。
【画幅】横版 3:2。
```

## 验收要点

- 四个角度的脸是不是同一个人；侧面的鼻子有没有变尖、变高（变了就回一句「侧面鼻子要和参考图一样小巧圆润」）。
- 发饰有没有跑到另一侧；背面能不能看到发髻和小枝的末端。
- 条纹是否宽窄一致；腰带颜色是否统一。
