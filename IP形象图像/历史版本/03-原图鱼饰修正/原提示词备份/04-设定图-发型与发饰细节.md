# 04 · 设定图：发型与发饰细节（单张）

- 对应：1 张图｜画风线：插画线｜画幅：横版 3:2（1536×1024）
- 作用：发饰「柊枝 + 小鱼」是这个 IP 的记号，也是 GPT 最容易画走样的地方（叶子变成枫叶、小鱼变成金鱼、位置跑到另一侧）。
  这张图把它们画清楚，以后发饰走样时把这张图传回去纠正。

## 提示词

```text
请以我上传的图为人物基准，画一张「发型与发饰细节设定图」。
【角色锁定｜必须与参考图是同一个人】二十岁左右的年轻女子。圆润的鹅蛋脸，脸颊饱满、带淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；小巧的鼻子只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后挽一个松松的低发髻。人物以修订版 02 号三视图和 04 号发饰图为准，原始插画只补充面部与画风。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝：两三片深绿色带尖刺的叶子，枝头串着一条金褐色、短胖圆腹的小鱼，躯干长高比约 1.5–1.8，含短尾的总长约为鱼身高度的 2 倍；圆眼、小短尾，鱼形以修订版 04 号发饰图为准。单张提示词没有另写时，发饰保持不变。
【画风】日系水彩插画：细腻的深褐色线稿，淡彩平涂加轻微晕染，低饱和的大地色，看得见纸张颗粒和水渍肌理，光线柔和、没有强烈阴影，画面安静、怀旧、有文学气息。
【禁止】不要改变脸型和五官比例；不要欧美写实脸；不要浓妆和夸张睫毛；不要高饱和荧光色；不要 3D 渲染或照片质感；手指数量要正确；画面里不要出现任何文字、水印、签名、边框。
【画面左半】同一个人物的头部特写四个，排成两行两列：正面、左侧面（能看到发饰的一侧）、右侧面（看不到发饰的一侧）、背面。画清楚：齐眉薄刘海的分缕、两鬓垂下的细卷发、耳朵露出多少、后脑低发髻的大小和松紧、后颈的碎发。
【画面右半】发饰的放大图三个，竖着排：① 整根发饰平放：一根褐色细枝，上面两三片深绿色、边缘带尖刺、表面有光泽的柊树叶，枝头串着一条烤成金褐色、短胖圆腹的小鱼，躯干长高比约 1.5–1.8，含短尾总长约为鱼身高度的 2 倍，鱼嘴微张、有圆眼睛和细密鳞片；② 发饰插在发髻旁的近景，看得出它是斜着插进头发里的，鱼头朝向后上方；③ 单独一片柊叶和单独一条小鱼的正反面。
【背景】暖灰米色纸面，淡淡水渍。不要任何文字标注、箭头、编号。
【要求】柊叶是硬质、深绿、边缘有尖刺的冬青类叶子，不是枫叶，不是花；小鱼是金褐色的短胖圆腹烤小鱼，躯干饱满、圆眼、小短尾；不要拉成长条，不要大飘尾金鱼，鱼形以修订版 04 为准。发饰始终在人物自己的左侧。
【画幅】横版 3:2。
```

## 发饰走样时的纠正句（复制即用）

```text
发饰画错了。请对照我上传的发饰设定图重画：一根褐色细枝斜插在人物左耳上方、靠近发髻，枝上两三片深绿色带尖刺的柊树叶，枝头串一条金褐色、短胖圆腹的烤小鱼，躯干长高比约 1.5–1.8，尾巴短小，以修订版 04 为准。其余画面不要改。
```
