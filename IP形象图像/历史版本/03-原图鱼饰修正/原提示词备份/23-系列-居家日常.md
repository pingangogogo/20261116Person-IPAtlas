# 23 · 系列：居家日常（14 张）

- 画风线：插画线｜画幅：横版 3:2（1536×1024）｜一条提示词出一张
- 特点：在一栋旧木屋里过的一天，从起床到关灯。横版，适合做电脑壁纸和横幅插图。
- 用法：上传基准图和设定图 → 先发「系列总提示词」→ 再逐条发「单张提示词」。

## 系列总提示词

```text
接下来我会分 14 次给你画面描述，每次只画一张图。所有图都要遵守下面的设定，直到我说「系列结束」。现在先不要画，只回复「明白」。
【角色锁定｜必须与参考图是同一个人】二十岁左右的年轻女子。圆润的鹅蛋脸，脸颊饱满、带淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；小巧的鼻子只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后挽一个松松的低发髻。人物以修订版 02 号三视图和 04 号发饰图为准，原始插画只补充面部与画风。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝：两三片深绿色带尖刺的叶子，枝头串着一条金褐色、短胖圆腹的小鱼，躯干长高比约 1.5–1.8，含短尾的总长约为鱼身高度的 2 倍；圆眼、小短尾，鱼形以修订版 04 号发饰图为准。单张提示词没有另写时，发饰保持不变。
【画风】日系水彩插画：细腻的深褐色线稿，淡彩平涂加轻微晕染，低饱和的大地色，看得见纸张颗粒和水渍肌理，光线柔和、没有强烈阴影，画面安静、怀旧、有文学气息。
【禁止】不要改变脸型和五官比例；不要欧美写实脸；不要浓妆和夸张睫毛；不要高饱和荧光色；不要 3D 渲染或照片质感；手指数量要正确；画面里不要出现任何文字、水印、签名、边框。
【本系列】《在家的一天》：场景是同一栋旧木屋——木地板的廊檐、榻榻米房间、纸拉门、一个种着花草的小院子、一间小厨房。14 张里屋子的样子要前后一致。每张一件家务或一个独处的瞬间，动作自然，不摆拍。家里养着一只三花猫，可以在角落里出现。
【服装规则】默认穿标准的宽条纹浴衣；做家务时用细带子束起袖子或加围裙；单张另写时以单张为准。
【发饰规则】柊枝小鱼发饰保留在原位；只有单张写明「发饰取下」时才取下，并且要把它画在画面里看得见的地方。
【画幅】横版 3:2。人物占画面三分之一到一半，其余留给屋子和光。不出现任何文字。
```

## 单张提示词

### 23-01 起床
清晨。她跪坐在刚叠好的被褥旁，一只手揉眼睛，一只手捂着嘴打哈欠，头发睡得有一撮翘起；穿着细条纹的睡衣。发饰取下，放在枕边的小瓷碟里。纸拉门外天色发白。主色：晨光的淡青与被褥的米白。

### 23-02 晾衣服
小院子里。她踮脚把一件白衬衣搭上竹竿，嘴里叼着一只木夹子，风把衣摆和她的袖子吹向同一边；竿上已经晾着一排衣物和一条条纹床单。主色：晴空蓝与布的白。

### 23-03 擦地板
她包着三角头巾、束着袖子，双手按着抹布在长长的木走廊上往前推着跑，脸上很有干劲；身后的地板湿润发亮，映出拉门的格子。发饰别在头巾外面。主色：地板的茶褐。

### 23-04 浇花
廊檐前摆着一排盆栽：爬着竹架的牵牛花、薄荷、一盆小松树。她蹲着用一只旧铜壶浇水，水珠在逆光里发亮，一只白粉蝶停在壶嘴附近。主色：叶子的绿与牵牛花的蓝紫。

### 23-05 午睡
夏日午后。她侧躺在榻榻米上睡着了，团扇盖在肚子上，一只手垫在脸下；旁边一只小猪形的陶制蚊香炉冒着一缕细烟，窗帘的影子在她身上轻轻晃动，三花猫蜷在脚边。主色：榻榻米的黄绿。

### 23-06 洗完澡
傍晚。她洗完澡坐在廊檐边，头发半湿，肩上搭着一条白毛巾，脸颊红扑扑的，仰头喝一瓶玻璃瓶装的牛奶；发饰取下，放在身边的木盘里。院子里的天是淡紫色的。主色：傍晚的淡紫与牛奶白。

### 23-07 缝补
她坐在窗边给一件衣服缝纽扣，正用牙咬断线头，眼睛低垂；膝边一只打开的针线盒，里面是各色线轴、顶针和一只插着针的小布包。主色：窗光的暖白与线轴的零星彩色。

### 23-08 插一枝花
她刚把一枝带叶的山茶插进竹筒花器，身子往后退了一点，歪着头端详，手里还拿着花剪；壁龛里的光线很暗，只有花和她的脸是亮的。主色：山茶红与深木色。

### 23-09 逗猫
她趴在榻榻米上，用一根狗尾草逗三花猫，猫立起身子扑过来，她笑得露出一点牙；猫的另一只眼睛其实在盯着她发饰上那条金褐色的小鱼。主色：猫的橘、黑、白。

### 23-10 看雨
她抱着膝盖坐在廊檐下，下巴搁在膝头，看院子里的雨；屋檐垂下一道雨帘，石水盆里一圈一圈的涟漪，八仙花被打得低着头。主色：雨的青灰与八仙花的蓝紫。

### 23-11 做晚饭
小厨房。她系着围裙在砧板上切白萝卜，身后灶上的锅冒着热气，她回过头来看向画外，像是有人刚进门；窗台上一排调料罐和一串挂着的干辣椒。主色：灶火的暖橙。

### 23-12 换季收纳
她跪坐在一只打开的藤箱前，怀里抱着一摞叠好的衣服，另一只手举起一把从箱底翻出来的旧团扇，有点怀念地笑；身边散着几包防虫的香袋。主色：藤箱的浅褐。

### 23-13 暖桌与橘子
冬夜。她窝在铺着厚被子的暖桌里，下巴搁在桌面上，面前一筐橘子，剥开的橘子皮摆成一朵花；三花猫从被子边探出脑袋，窗外在下雪。主色：橘子橙与被子的暗红格子。

### 23-14 关灯
夜深了。被褥已经铺好，她抱着一本书跪坐在枕边，伸手去拉吊灯的灯绳；纸拉门上映着院子里竹叶的影子，月光是淡蓝色的。发饰取下，放在枕边的小瓷碟里（和第一张呼应）。主色：灯的暖黄与月光的淡蓝。
