## 二、两条画风线

- **插画线**：日系水彩插画，接近真实头身比例，安静、怀旧。适合壁纸、海报、明信片、系列组画。
- **Q 版线**：二头身手绘贴纸，带米白色贴纸白边，背景透明。适合表情包、图标、界面点缀、周边。

每个系列都标了默认用哪条线。想换线：把该文档「系列总提示词」开头的锁定段整段换成另一条线的锁定段即可。

## 三、不变项（身份锚点）

1. **脸**：圆润的鹅蛋脸，脸颊饱满，淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；
   鼻子小巧只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。
2. **头发**：乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后一个松松的低发髻。
   （Q 版：黑色波波头，圆弧扇贝形齐刘海，头顶偏右后方一个圆丸子。）
3. **标志元素「绿叶 + 小鱼」**：柊树小枝（带尖刺的深绿叶子）串一条金褐色小鱼，来自日本节分的「柊鰯」。
   这是整个 IP 的记号。头饰可以换，但建议每张图里都以某种形式留下「小鱼」或「尖叶」中的至少一个
   （发饰、吊坠、衣服印花、扇面、杯子图案、背景小物都可以）。
4. **气质**：安静、温和、有一点出神；开心也是含蓄的开心，不夸张。
5. **画法**：同一条线内，线条颜色、上色方式、颗粒质感保持一致。

## 四、可变项

姿态动作、表情、服装款式与颜色、头饰（在保留记号的前提下）、手持道具、场景、季节、天气、时间、
光线、整体色调、镜头远近与角度、画幅比例、形态（Q 版 / 像素 / 剪纸 / 木版画……见 34、35 号）。

## 五、标准服装与道具（单张没有另写时用这一套）

- 插画线：暖米色与炭灰褐色相间的宽条纹浴衣，白色半襟，墨绿色暗纹腰带；
  手持淡青绿色团扇，扇面是白色金鱼与水纹，竹骨竹柄。
- Q 版线：米白底、灰色细竖条纹的和服，白色交领。

## 七、锁定段 · 插画线（各文档的提示词里已嵌入）

```text
【角色锁定｜必须与参考图是同一个人】二十岁左右的年轻女子。圆润的鹅蛋脸，脸颊饱满、带淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；小巧的鼻子只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后挽一个松松的低发髻。
【标志发饰】人物左耳上方（画面右侧）斜插一根柊树小枝：两三片深绿色带尖刺的叶子，枝头串着一条烤成金褐色的小鱼。单张提示词没有另写时，发饰保持不变。
【画风】日系水彩插画：细腻的深褐色线稿，淡彩平涂加轻微晕染，低饱和的大地色，看得见纸张颗粒和水渍肌理，光线柔和、没有强烈阴影，画面安静、怀旧、有文学气息。
【禁止】不要改变脸型和五官比例；不要欧美写实脸；不要浓妆和夸张睫毛；不要高饱和荧光色；不要 3D 渲染或照片质感；手指数量要正确；画面里不要出现任何文字、水印、签名、边框。
```

## 八、锁定段 · Q 版线（各文档的提示词里已嵌入）

```text
【角色锁定｜必须与参考图是同一个形象】二头身 Q 版小人。大大的圆头，横向椭圆的脸；黑色波波头，圆弧扇贝形齐刘海，头顶偏右后方一个圆圆的丸子发髻；深褐色大圆眼、带两点白色高光；粉色椭圆腮红；一点小鼻子和小嘴；露出一只圆耳朵。
【标志发饰】丸子发髻下方别着两片嫩绿色带尖角的小叶子，叶子下面垂着一条金黄色的小鱼吊坠。单张提示词没有另写时，发饰保持不变。
【画风】手绘贴纸风：深褐色粗描边，色块平涂，带毛毡或牛皮纸般的细颗粒质感；低饱和暖色；人物外圈一圈略不规则的米白色贴纸白边，白边外有极淡的投影；背景透明（做不到透明就用纯白）。
【禁止】不要改成写实比例；不要改变刘海形状和丸子头；不要渐变光泽、3D、金属质感；不要高饱和荧光色；除单张指定的符号外不要出现文字和水印；肢体不要被画面边缘裁掉。
```

## 九、想整体改设定时

1. 只改本文第七、八节的锁定段。
2. 用编辑器的「在文件夹中替换」，把各文档里旧的句子替换成新的句子（锁定段在所有文档里逐字相同）。
3. 重新生成 02–06 号设定图，作为新的基准图。
