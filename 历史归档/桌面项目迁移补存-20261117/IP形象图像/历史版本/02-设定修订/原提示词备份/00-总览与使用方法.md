# 00 · 总览与使用方法

这个文件夹是一整套给 GPT 生图用的提示词。人物始终是同一个人，变的是姿态、状态、形态、头饰、色彩、服装、场景和镜头。
一份文档对应一张图（02–06）或一个系列（10–42）。全部做完是 466 张图。

## 一、三步上手

1. **准备基准图**。基准图就是项目里现有的几张素材，在 `crates/app/assets/decor/` 下：
   插画线用 `i-kimono.jpg`、`a-portrait.jpg`、`a-tea.jpg`；Q 版线用 `f-wave.png`、`s-dev.png`、`f-tea.png`、`f-nap.png`、`f-done.png`。
2. **先做设定图**。按 02、03、04、05、06 的顺序各出一张。这五张是以后所有系列的「标准答案」，满意了再往下做。
3. **挑一个系列开始**。每个系列都是同一个流程：
   - 新开一个对话，上传基准图和设定图；
   - 把文档里「系列总提示词」的整段复制过去，等它回复「明白」；
   - 把「单张提示词」一条一条发过去，一条出一张；
   - 全部出完，发「收尾」里的那一段，得到一张总览图。

一个系列用一个对话，不要在同一个对话里换系列。对话太长、开始跑偏时，新开一个对话，重新上传图、重新发总提示词，接着没做完的编号往下做。

## 二、两条画风线

| | 插画线 | Q 版线 |
|---|---|---|
| 样子 | 日系水彩插画，接近真实比例，安静、怀旧 | 二头身手绘贴纸，米白色白边，透明背景 |
| 适合 | 壁纸、海报、明信片、组画 | 表情包、图标、界面点缀、周边 |
| 基准图 | `i-kimono.jpg` | `f-wave.png` |
| 标准衣服 | 暖米色与炭灰褐相间的宽条纹浴衣，墨绿腰带，淡青绿金鱼团扇 | 米白底灰色细竖条纹的和服 |
| 发型 | 乌黑微卷的短发，齐眉薄刘海，脑后低发髻 | 黑色波波头，扇贝形齐刘海，头顶一个丸子 |
| 记号 | 左耳上方的柊枝，枝头串一条金褐色小鱼 | 两片嫩绿小叶子，垂一条金黄色小鱼 |

不管哪条线，让人认出「是她」的都是这几样：齐刘海的黑发、圆脸和沉静的大眼睛、**绿叶加小鱼**的发饰、条纹。

## 五、把几份拼起来用

各份文档里的句子可以拆开重组。一张新图 = 锁定段 + 衣服 + 姿势 + 场景 + 镜头 + 颜色：

```text
（先发任意一份插画线文档的系列总提示词，等它回复「明白」，再发下面这段）
服装：【从 27、28、29 号里抄一条的服装描述】。
姿势：【从 32 号里抄一条】。
场景：【从 23、26 号里抄一条的场景，或者自己写】。
镜头：【从 33 号的镜头词表里挑一句】。
颜色：【从 31 号里挑一个色系，或者写「主色：……」】。
画幅：【横版 16:9 / 竖版 2:3 / 方形 1:1】。
```

例子：

```text
服装：一件长长的卡其色风衣敞开着，里面是墨绿色的高领毛衣，脖子上松松地搭着一条宽条纹的长围巾。
姿势：背对观众站立，上身和头向她的左肩方向回转，露出四分之三的脸，一只手抬起拢耳边的头发。
场景：深秋的黄昏，一整片山坡的芒草被夕阳照成金色。
镜头：全景，人物全身入画，占画面高度的一半；人物靠右，左侧留出大片颜色平缓的天空。
颜色：主色是芒草的金与夕阳的橙。
画幅：横版 16:9。
```

想让某个系列换一条画风线：把那份文档「系列总提示词」里从「【角色锁定」到「【禁止】」的四行，整段换成 01 号文档里另一条线的四行。

## 六、建议的制作顺序

1. 02 → 03 → 04 → 05 → 06：五张设定图。
2. 32（姿态）和 27（和风换装）：背景简单，最容易看出人物稳不稳。这两套稳了，后面都稳。
3. 18（表情包）和 20（工作与电脑）：Q 版里最实用的两套。
4. 40（界面与壁纸素材）：可以直接用进桌面软件。
5. 其余按喜好。

## 七、几条约定

- **锁定段**：每条「系列总提示词」开头那四行（角色锁定、标志发饰、画风、禁止）在所有文档里逐字相同；34、41 号要换画风和材质，只带前两行；42 号不画人物，没有这一段。想改人物设定，照 01 号第九节做。
- **文字**：除非提示词里写明，否则图里都不出现字。要加字（日期、祝福语、软件名），出图以后自己加，比让它写可靠。
- **尺寸**：文档里写的比例和像素是建议值。它给不了那么大时，会按最接近的比例出图，需要更大就再放大一次。
- **一次一张**：一条提示词只让它画一张。一次要很多张，人物容易走样。
- **不满意**：先翻 99 号的「出图不对时这样说」，照着发一句，比重新写整条提示词有效。
- **伙伴没有名字**：人物和 36 号里的四个伙伴都没有起名，留给你定。
