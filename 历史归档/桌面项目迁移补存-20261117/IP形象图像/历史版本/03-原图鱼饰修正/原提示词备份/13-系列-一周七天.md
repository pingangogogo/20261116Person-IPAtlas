# 13 · 系列：一周七天（7 张）

- 画风线：Q 版线｜画幅：方形 1:1（1024×1024），透明背景｜一条提示词出一张
- 用法：上传新版 06 号 Q 版设定图（`IP形象图像/02-设定修订/06-设定图-Q版标准形象.png`） → 先发「系列总提示词」→ 再逐条发「单张提示词」。

## 系列总提示词

```text
接下来我会分 7 次给你描述，每次只画一张贴纸。所有贴纸都要遵守下面的设定，直到我说「系列结束」。现在先不要画，只回复「明白」。
【角色锁定｜必须与参考图是同一个形象】从插画角色重新设计的约 2.7 头身水彩 Q 版女子，身份以修订版 06 号 Q 版设定图为准。圆润的小鹅蛋脸、柔粉腮红、暖白肤色；适中大小的深褐色眼睛，只有微小高光，眼神安静温和；细短眉、小鼻子和小嘴。乌黑微卷的短发，自然分缕的碎齐刘海，两鬓几缕细卷发，后脑一个松松的低发髻。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝：两三片深绿色带尖刺的叶子，枝头串着一条金褐色、短胖圆腹的小鱼，躯干长高比约 1.5–1.8，含短尾的总长约为鱼身高度的 2 倍；圆眼、小短尾，鱼形以修订版 04 号发饰图为准。单张提示词没有另写时，发饰保持不变。
【画风】水彩 Q 版：细而有轻重的深褐色线条，柔和水彩晕染与纸张颗粒，低饱和暖色；轮廓自然，不加贴纸白边。背景透明，单张另写时以单张为准，做不到透明则用纯白。
【禁止】不要改变圆润脸型、自然碎齐刘海和后脑低发髻；不要放大眼睛或高光；不要矢量粗线、渐变光泽、3D 或金属质感；不要高饱和荧光色；除单张指定的符号外不要出现文字和水印；肢体不要被画面边缘裁掉。
【默认服装】暖米色与炭灰褐相间的宽条纹浴衣，白色半襟，墨绿色腰带；单张另写时以单张为准。
【本系列】《一周七天》：周一到周日每天一张，画的是这一天的心情。7 张大小、线条粗细和水彩质感完全一致，每张有一个点缀色（用在小道具或符号上）。
【画幅】方形 1:1，小人居中、占画面七到八成，四周留透明边距。默认不写字。
```

## 单张提示词

### 13-01 周一 · 还没醒
周一。她站着却闭着眼，身体向一侧歪，一只手端着冒热气的咖啡杯，头顶冒着三个由小到大的睡眠泡泡，头发翘起一缕。点缀色：灰蓝。

### 13-02 周二 · 埋头干活
周二。她坐在浅灰色笔记本电脑后面（盖子中央一片绿色尖叶标记），只露出头和两只敲键盘的手，眉毛微微皱着很认真，额头扎着一条细布带。点缀色：草绿。

### 13-03 周三 · 撑到一半
周三。她双手托着一只比脸还大的饭团正要咬，眼睛闪着两颗小星星，脚边放着一壶茶。表示「吃饱了继续」。点缀色：海苔墨绿。

### 13-04 周四 · 电量不足
周四。她趴在桌沿上，脸颊被挤扁，眼睛变成两道横线，头顶漂着一个只剩一格的电池符号，手里还捏着一支笔。点缀色：橙红（只用在电池那一格）。

### 13-05 周五 · 下班啦
周五。她双手高高举起跳离地面，笑得眼睛弯成月牙，小鱼吊坠甩了起来，身边散着几片彩纸屑和两颗小星星。点缀色：暖黄。

### 13-06 周六 · 赖床
周六。她裹在米色的被子卷里只露出脸，像一只寿司卷，睡得脸颊红扑扑，嘴角一点口水，枕边趴着一只小金鱼玩偶。点缀色：淡粉。

### 13-07 周日 · 晒太阳
周日。她坐在一小块草地上，身旁晒着一床条纹被子，双手捧着茶杯，仰脸闭眼晒太阳，头顶一个小小的太阳符号。点缀色：阳光橙。

## 需要带字时（每张末尾追加一句）

```text
本张允许出现文字：在小人左上方加一个圆角小标签，里面写「周一」两个字，深褐色圆体字，标签底色用本张的点缀色，标签用细深褐线勾边和淡彩填色。
```

## 扩展：同一套的插画线版本

想要一套安静的插画版「一周」，把总提示词里的锁定段换成插画线的锁定段，画幅改成竖版 2:3，再用这 7 句：

1. 周一：清晨的电车站台，她抱着布包打哈欠，晨雾未散。
2. 周二：书桌前伏案写字，台灯下摆满纸张。
3. 周三：午后的茶室角落，她对着一碟点心出神。
4. 周四：雨天的窗边，她额头抵着玻璃发呆。
5. 周五：傍晚的商店街，她拎着刚买的鲜花轻快地走。
6. 周六：旧书店里踮脚取高处的书。
7. 周日：阳台上晒被子，她抱着枕头眯眼看天。
