# 使用指南

本库提供角色设定、独立图片、带字版本与软件小尺寸资源。先按用途选择文件，再根据当前基准延续角色；涉及素材使用权限时，查看[来源与许可](来源与许可.md)。

## 选择素材

| 需要 | 选择 |
| --- | --- |
| 浏览主题、快速选图 | [README系列导航](../README.md#原系列导航)及各目录总览 |
| 独立插画、表情、装饰或壁纸 | `IP形象图像/10-*`～`42-*`内对应编号PNG |
| 已排好文字的表情、祝福和月历 | [可选带字扩展](../IP形象图像/可选带字扩展/) |
| 软件界面中的透明角色与图标 | [软件小图素材](../IP形象图像/软件小图素材/)内指定像素目录 |
| 继续生成同一角色 | 当前角色基准、原始参考图和对应系列提示词 |

总览用于浏览，实际排版优先取独立单图。完整背景图与透明PNG分别使用，不要把预览图中的背景当成透明素材的一部分。

## 锁定当前角色

Q版生成时，按以下三张参考锁定身份，再加入对应系列的动作与道具要求：

1. [06 Q版标准形象](../IP形象图像/00-角色基准/06-设定图-Q版标准形象.png)：确定约2.7头身、脸型、眼睛、自然碎刘海、低后发髻及水彩画风。
2. [原始素材 i-kimono.jpg](../参考图/原始素材/i-kimono.jpg)：确定鱼饰的嘴、眼、鳃盖、色斑及短鱼头轮廓。
3. [04 发型与发饰细节](../IP形象图像/00-角色基准/04-设定图-发型与发饰细节.png)：核对低发髻、两鬓细卷发和鱼饰与柊叶的连接关系。

插画比例另参考[02 三视图与比例](../IP形象图像/00-角色基准/02-设定图-三视图与比例.png)；服装与随身物件参考[05 标准服装与随身小物](../IP形象图像/00-角色基准/05-设定图-标准服装与随身小物.png)。文字要求见[角色基准设定](../IP形象提示词/01-角色基准设定.md)及[各系列提示词](../IP形象提示词/)。

鱼饰是一枚金灰褐色鱼头与很短前段，后部被深绿柊叶遮住，不补完整鱼身、鱼尾或圆腹。标准位置在人物自己的左耳上方，正面时位于画面右侧；具体系列要求移至其他位置时，遵循该张提示词。只有单张明确要求时才加入腰间或包上的小鱼配饰，不能用它代替头饰。

标准服装为暖米与炭灰褐宽条纹浴衣、白半襟和墨绿腰带。换装系列按单张要求调整服装，仍保持同一脸型、发型与角色身份。

[历史版本](../IP形象图像/历史版本/)仅供查看修订过程，**不要使用其中的旧图或旧提示词继续生成**。尤其不要恢复旧比例、高丸子头或完整长鱼形头饰。

## 文字与2027年月历

104张带字扩展由原图加文字排版得到，按节气、月份、星期、传统节日、情绪、问候分别存放。原始无字图未被覆盖。部分透明图为容纳文字扩展了透明画布，带字版尺寸可能与无字版不同。

[12个月历](../IP形象图像/可选带字扩展/12-月历十二个月/)使用**2027年公历**，每周按**周日、周一、周二、周三、周四、周五、周六**排列。全年365个日期与星期位置已核验。文件名中的`2027月历`表示固定年份，不能直接用于其他年份；需要重排时，从[月份无字原图](../IP形象图像/12-月历十二个月/)开始。

带字扩展的来源、输出尺寸与SHA256见仓库根相对路径`IP形象图像/可选带字扩展任务.json`。

## 软件素材与实际像素

软件素材共有82款设计：原43～48的46款保留，51新增30款物件图标与6款职业人物。尺寸导出共245张PNG（原185张加51的60张），另有2份ICO和22张兼容资源；49、50及51复用的24张人物均来自既有原图，不另计设计。`原稿/`保留原生生成尺寸，`24/`、`32/`等数字目录内的PNG宽高即为该像素值。

| 系列 | 内容 | 导出尺寸 |
| --- | --- | --- |
| 43 分组角色 | 11个分组的角色装饰 | 128×128、256×256 |
| 44 分组图标 | 11个分组的独立物件图标 | 24×24、32×32、48×48、64×64、128×128 |
| 45 软件空状态 | 应用、文档、投递等空状态 | 128×128、256×256 |
| 46 操作反馈 | 扫描、完成、重复、类型或启动错误、保存 | 128×128、256×256 |
| 47 操作引导 | 拖入、排序、跨组、打开、更换装饰 | 128×128、256×256 |
| 48 窗口小助手 | 左右引导、提醒、帮助、专注、小憩 | 128×128、256×256 |
| 49 分组角落 | 40张既有透明角色选集 | 480×480 |
| 50 应用图标 | 专属桌面与个人工具箱各一套 | 16、20、24、32、40、48、64、96、128、256像素，另ICO |
| 51 扩展分组 | 30套小图标与右上人物 | 图标128×128、人物400×400 |

这些导出以透明主体范围归一化，在方形画布内保留安全边距。选择接近目标显示尺寸的导出，保持纵横比；缩放原稿后仍应检查实际显示效果。验收预览已将图标按真实像素放在浅色与深色背景上，见[预览目录](../IP形象图像/软件小图素材/验收预览/)。

43、44系列使用相同分组键：

| 键 | 分组 | 键 | 分组 |
| --- | --- | --- | --- |
| `self` | 自研 | `office` | 办公 |
| `dev` | 开发 | `sci` | 科研 |
| `chat` | 通讯 | `media` | 影音 |
| `sys` | 系统 | `proj` | 项目 |
| `read` | 资料 | `admin` | 事务 |
| `sort` | 待整理 | | |

[兼容资源包](../IP形象图像/软件小图素材/专属桌面装饰包/)中的`s-*.png`来自43系列256像素角色装饰，`i-*.png`来自44系列128像素图标。对应编号、文件名、尺寸与SHA256见包内`资源映射.json`。这些文件与尺寸导出属于同一套设计的不同交付形式。

[49分组角落](../IP形象图像/软件小图素材/49-分组角落/)从40张不同的既有透明角色图选取并导出，按主体范围居中、保留约7%边距。`f-group-01`至`10`依次对应自研、办公、开发、科研、通讯、影音、系统、项目、资料、事务，`11`至`40`为新增分组备用。在专属桌面中，每个分组将选定的资源名保存在`layout.json`的`corner`字段中；改名或调整顺序不换图，备用用完后留空。先看[选集预览](../IP形象图像/软件小图素材/49-分组角落/选集预览.png)，逐张来源、尺寸与校验值见该目录的`资源映射.json`。

[50应用图标](../IP形象图像/软件小图素材/50-应用图标/)中，专属桌面使用44-11待整理图标，个人工具箱使用44-07绿色齿轮与扳手。每套提供十个实际像素PNG和含相同十档的`icon.ico`；裁紧透明主体、居中，每边保留画布的1/32且至少1像素。软件内的托盘、标题栏、任务栏与快捷方式均使用同一套形象，按显示尺寸取图。来源及ICO校验值见该目录的`资源映射.json`，浅深底效果见[实际尺寸预览](../IP形象图像/软件小图素材/50-应用图标/实际尺寸预览.png)。

[51扩展分组](../IP形象图像/软件小图素材/51-扩展分组/)将`i-extra-01`至`30`的小图标与`s-extra-01`至`30`的右上人物按相同编号配成30套。前6套依次为工程、设计、远程、网络、投研、游戏，配套人物为新生成的职业角色；后24套供新增分类使用，人物从既有透明角色中选取，避开49、43及软件已使用的来源，这24张选集不计作新设计。30款物件图标由OpenAI生图工具参考44系列生成，图标与职业人物的原始atlas保存在51的`原稿/`目录。选图见[图标预览](../IP形象图像/软件小图素材/51-扩展分组/图标预览.png)及[人物预览](../IP形象图像/软件小图素材/51-扩展分组/人物预览.png)，来源与配对见[资源映射](../IP形象图像/软件小图素材/51-扩展分组/资源映射.json)。

素材先保存到本库并登记映射，再复制到软件资源。专属桌面将默认10套与51新增30套组成分类图案池，为旧版未设置`art`的分组及新分类自动分配未占用的整套图标与人物；选定资源名存入`layout.json`的`art`字段，改名或调序后保持，用尽后留空。已有自选图名保留；升级只补一次新资源，不覆盖同名自定义PNG/JPG/JPEG，补齐后用户删除的图不再自动补回。

## 像素画与无缝纹样

[34-06像素画](../IP形象图像/34-画风与材质/34-06-像素画.png)原稿为**64×64像素、15色**。[放大预览](../IP形象图像/34-画风与材质/34-06-像素画-放大预览.png)为最近邻放大，仅方便观看。需要保留像素边缘时，使用整数倍最近邻缩放，避免平滑插值。

[42-纹样与边框](../IP形象图像/42-纹样与边框/)中，01～07支持横向、纵向连续平铺，09支持左右连续拼接。平铺时使用该目录根下的最终PNG，保持单元尺寸与边缘，不裁掉边界或加留白。`拼接预览/`是2×2检查图，不作为单个纹样单元。08、10按独立构图使用，不按四边无缝纹样处理。

## 文件尺寸与清单

图片保留实际原生尺寸，不能将全部素材统称为4K。透明素材保留PNG的Alpha通道，导出时不要额外加纸底、灰雾、光晕或贴纸白边；需要背景时，在排版中单独添加。

以下清单中的文件路径以**仓库根目录**为起点，复制或迁移整个仓库后仍按相对位置查找：

- `IP形象图像/生成任务.json`：461张原系列单图。
- `IP形象图像/系列总览任务.json`：28张总览与封面。
- `IP形象图像/可选带字扩展任务.json`：104张带字扩展。
- `IP形象图像/软件小图素材/软件素材生成任务.json`：46张软件原稿及尺寸导出记录。
- `IP形象图像/软件小图素材/专属桌面装饰包/资源映射.json`：22张兼容资源。
- `IP形象图像/软件小图素材/49-分组角落/资源映射.json`：40张选集的原图、导出、默认分组与备用分配。
- `IP形象图像/软件小图素材/50-应用图标/资源映射.json`：两套应用图标的来源、十档尺寸与ICO校验值。
- `IP形象图像/软件小图素材/51-扩展分组/资源映射.json`：30套扩展分类的图标来源、既有人物来源、配对及尺寸导出。

按文件路径、宽高和SHA256核对资产。生成提示词用于复现设计要求，不能保证重新生成的图片逐像素相同。
