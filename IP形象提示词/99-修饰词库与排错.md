# 99 · 修饰词库与排错

这一份不对应某张图，是工具书：出图不对时怎么说；自己想写新画面时，有哪些词和句式可以直接拿来用。

## 一、出图不对时这样说

在同一个对话里直接发右边这句。一次只改一个问题，改好了再改下一个。

| 问题 | 发这句 |
|---|---|
| 脸不像她 | 脸和参考图不是同一个人。请对照我上传的参考图重画脸：圆润的鹅蛋脸、深色眼睛（插画线大而圆，Q 版适中且高光微小）、细而平的短眉、小嘴；其余不要动。 |
| 发型变了 | 发型不对。应该是乌黑微卷的短发、齐眉的薄刘海、两鬓几缕细卷发、脑后一个松松的低发髻。请只改头发。 |
| 发饰没了 | 发饰漏了。请在她左耳上方（画面右侧）加上柊树小枝：两三片深绿色带尖刺的叶子，枝头串着一条金褐色的小鱼。其余不要动。 |
| 发饰跑到另一边 | 发饰的位置反了。它应该在人物自己的左侧，也就是正面看时的画面右侧。请改过来。 |
| 发饰变成别的东西 | 发饰画错了。不是花，不是羽毛，是一小枝带尖刺的绿叶加一条小鱼。请对照发饰设定图重画发饰。 |
| 条纹变细或变色 | 衣服的条纹不对。应该是暖米色与炭灰褐相间的竖向宽条纹，每道大约两指宽。请只改衣服的花纹。 |
| 颜色太艳 | 颜色太鲜艳了。请把整体饱和度降下来，换成低饱和的大地色，像晒旧了的水彩。 |
| 太写实、像照片或 3D | 画法不对。请改回日系水彩插画：细的深褐色线稿、淡彩平涂、看得见纸的颗粒，不要光泽和立体渲染。 |
| 出现了文字或水印 | 画面里出现了文字。请把所有文字、字母、签名、水印去掉，那些地方用周围的背景补上。 |
| 手画坏了 | 手画错了。请重画手：每只手五根手指，姿势自然；如果画不好，让手藏在袖子里或者拿着团扇。 |
| 人物太大或太小 | 人物在画面里太大（太小）。请让人物占画面高度的【几分之几】，其余内容不变。 |
| 头或脚被裁掉 | 人物被画面边缘裁掉了。请把镜头拉远一点，从头顶到脚尖完整入画，四周留出空白。 |
| 背景太乱 | 背景的东西太多了。请只留下【两三样】，其余去掉，远处用淡淡的晕染带过。 |
| 表情不对 | 表情不对。我要的是【表情】：【眼睛怎样、眉毛怎样、嘴怎样】。请只改脸上的表情。 |
| 系列里这一张和前面不像 | 这一张和前面几张不像同一套。请对照第【几】张，把人物的脸、线条粗细和上色方式改得和它一致，构图不变。 |
| 年纪画小或画老了 | 年纪不对。她是二十岁左右的年轻女子，请按这个年纪重画脸和身材比例。 |
| Q 版：出现粗线白边 | 请对照基准版 06，改为细深褐线和柔和水彩晕染，去掉贴纸白边，保持人物与道具完整。 |
| Q 版：背景不透明 | 本张要求透明背景，请去掉背景，导出为 PNG；人物和水彩质感不变。06 设定图的暖灰纸底保留。 |
| Q 版：头身比例偏离 | 比例不对。应该是约 2.7 头身，头大、身体小但不挤成一团。请按基准版 06 的比例重画。 |
| Q 版：太像矢量贴纸 | 请改回基准版 06 的水彩感觉：细而有轻重的深褐线、柔和晕染和纸张颗粒，不加贴纸白边。 |
| 怎么改都不对 | 新开一个对话，重新上传基准图和设定图，重新发系列总提示词，再发这一条。旧对话里画坏的图会一直影响后面的图。 |

## 二、只改一处的句式

已经有一张满意的图，只想动一个地方：

```text
请保持这张图的构图、人物、表情和画法完全不变，只把【要改的东西】改成【新的样子】。
```

常用的几种：

```text
请保持其余完全不变，只把季节换成【春 / 夏 / 秋 / 冬】：植物、光线和她身上的小配件跟着换。
```

```text
请保持其余完全不变，只把时间换成【清晨 / 正午 / 黄昏 / 深夜】：只改光线和天空的颜色。
```

```text
请保持姿势和场景完全不变，只把衣服换成【服装描述】；发饰保留。
```

```text
请把这张图改成【横版 16:9 / 竖版 9:16 / 方形 1:1】：人物不变，向【左右 / 上下】补画背景，补出来的部分要安静、细节少。
```

```text
请把这张图里的人物单独抠出来，背景透明，边缘干净，导出为 PNG。
```

## 三、两条万能模板

想画一张哪份文档里都没有的图，用这两段。把方括号里的内容换成自己的，整段发出去（记得先上传基准图和设定图）。

### 插画线

```text
请画一张图。
【角色锁定｜必须与参考图是同一个人】二十岁左右的年轻女子。圆润的鹅蛋脸，脸颊饱满、带淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；小巧的鼻子只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后挽一个松松的低发髻。人物脸型、发型和服装以 02 号三视图为准；鱼饰始终逐形复刻原始 i-kimono.jpg，04 号图仅作复刻细节辅助。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝，带两三片深绿色尖刺叶；枝头的金灰褐色烤鱼头饰必须逐形复刻 `参考图/原始素材/i-kimono.jpg`，`参考图/原始素材/a-portrait.jpg` 仅补充角度：保留原图鱼头与很短前段的轮廓、微张的嘴、眼睛、鳃盖、色斑及枝叶遮挡关系，后部与枝叶连接。不另设身体或尾部比例，不擅补大圆腹、扇尾或突出的背鳍。`IP形象图像/00-角色基准/04-设定图-发型与发饰细节.png` 仅作复刻细节辅助。单张提示词没有另写时，发饰保持不变。
【画风】日系水彩插画：细腻的深褐色线稿，淡彩平涂加轻微晕染，低饱和的大地色，看得见纸张颗粒和水渍肌理，光线柔和、没有强烈阴影，画面安静、怀旧、有文学气息。
【禁止】不要改变脸型和五官比例；不要欧美写实脸；不要浓妆和夸张睫毛；不要高饱和荧光色；不要 3D 渲染或照片质感；手指数量要正确；画面里不要出现任何文字、水印、签名、边框。
【画面】【季节和时间】，【地点】。她【正在做什么，身体的姿势】，【表情和视线】；穿【衣服，没有特别要求就写「标准的宽条纹浴衣」】，手里【拿着什么】。周围有【两三样点明地点和季节的东西】。
【光线】【光从哪里来，什么颜色】。
【镜头】【远近和角度】，人物在画面的【位置】，【哪一侧】留白。
【颜色】主色：【一两种颜色】。
【画幅】【比例】。不出现任何文字。
```

### Q 版线

```text
请画一张贴纸。
【角色锁定｜必须与参考图是同一个形象】从插画角色重新设计的约 2.7 头身水彩 Q 版女子，身份以基准版 06 号 Q 版设定图为准。圆润的小鹅蛋脸、柔粉腮红、暖白肤色；适中大小的深褐色眼睛，只有微小高光，眼神安静温和；细短眉、小鼻子和小嘴。乌黑微卷的短发，自然分缕的碎齐刘海，两鬓几缕细卷发，后脑一个松松的低发髻。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝，带两三片深绿色尖刺叶；枝头的金灰褐色烤鱼头饰必须逐形复刻 `参考图/原始素材/i-kimono.jpg`，`参考图/原始素材/a-portrait.jpg` 仅补充角度：保留原图鱼头与很短前段的轮廓、微张的嘴、眼睛、鳃盖、色斑及枝叶遮挡关系，后部与枝叶连接。不另设身体或尾部比例，不擅补大圆腹、扇尾或突出的背鳍。`IP形象图像/00-角色基准/04-设定图-发型与发饰细节.png` 仅作复刻细节辅助。单张提示词没有另写时，发饰保持不变。
【画风】水彩 Q 版：细而有轻重的深褐色线条，柔和水彩晕染与纸张颗粒，低饱和暖色；轮廓自然，不加贴纸白边。背景透明，单张另写时以单张为准，做不到透明则用纯白。
【禁止】不要改变圆润脸型、自然碎齐刘海和后脑低发髻；不要放大眼睛或高光；不要矢量粗线、渐变光泽、3D 或金属质感；不要高饱和荧光色；除单张指定的符号外不要出现文字和水印；肢体不要被画面边缘裁掉。
【服装】暖米色与炭灰褐相间的宽条纹浴衣，白色半襟，墨绿色腰带。（要换衣服就改这一句）
【画面】她【正在做什么】，【身体的姿势】，【表情：眼睛怎样、嘴怎样】；身边【一件主要道具】和【最多两个小点缀或漫画符号】。
【颜色】点缀色：【一种颜色】。
【画幅】方形 1:1，小人连同道具占画面七到八成，四周留透明边距。不写字。
```

## 四、词库

往模板的方括号里填东西时，从这里挑。句子都可以直接抄。

### 光线

- 清晨的光，淡青色，还有一点薄雾，影子很淡
- 上午的窗光，从侧面照进来，在地上投出窗格的影子
- 正午的光，明亮、偏白，影子短，树荫下有斑驳的光点
- 午后的斜光，暖黄色，空气里看得见浮尘
- 黄昏的逆光，人物的轮廓有一圈金边，影子拉得很长
- 阴天的光，柔和、均匀，几乎没有影子，颜色偏灰
- 雨天的光，青灰色，地面和叶子反着湿润的亮
- 雪天的光，明亮的蓝白色，雪地把光反到人的脸上
- 灯下的光，一盏暖黄的灯只照亮人物和手边，周围是暗的
- 灯笼和烛火的光，橙红色，轻轻摇晃，脸上有暖光
- 月光，淡蓝色，清冷，物体的边缘发银白
- 屏幕的光，淡蓝白色，从正前方照在脸上，身后是暗的

### 天气与空气

薄雾、晨露、毛毛雨、骤雨初歇、屋檐滴水、雨后的水洼、彩虹、微风、大风吹起衣袖、飞花、落叶、柳絮、蝉鸣的午后、积雨云、晚霞、火烧云、初雪、大雪、雾凇、霜、星空、银河、满月、新月、萤火虫。

### 表情

| 表情 | 怎么写 |
|---|---|
| 浅笑 | 嘴角微微上扬，眼睛柔和，不露牙 |
| 开心 | 眼睛弯成月牙，嘴张开，脸颊更红 |
| 害羞 | 视线往旁边躲，脸红到耳根，用袖子或扇子挡着嘴 |
| 出神 | 视线落在很远的地方，嘴微微张着，没有表情 |
| 专注 | 眉头微微收紧，嘴抿成一条线，眼睛盯着手里的东西 |
| 惊讶 | 眼睛睁圆，眉毛抬高，嘴张成小圆形 |
| 困 | 眼皮垂到一半，打着哈欠，眼角有一点泪 |
| 得意 | 闭着眼，下巴微抬，嘴角翘起 |
| 委屈 | 眉毛成八字，嘴往下撇，眼睛里含着泪 |
| 生气 | 鼓着脸颊，眉毛压低，扭过头不看人 |
| 为难 | 一边眉毛高一边眉毛低，嘴角勉强地笑，脸旁一滴汗 |
| 满足 | 闭着眼，深吸一口气，脸上松弛，微微仰头 |
| 怀念 | 低头看着手里的东西，笑里带一点落寞 |
| 调皮 | 闭起一只眼，吐出一点舌尖 |

### 手在做什么

托着腮、拢耳边的头发、按着被风吹起的头发、用扇子挡着嘴、双手捧着杯子、双手拢在袖子里、提着衣摆、撑在身体两侧、抱着膝盖、背在身后、伸手去接（雨、雪、花瓣）、指着远处、搭在额前遮光、挥手、比出「嘘」、双手合十、抱着书、捧着脸。

### 视线

看向观众、看向画外的远处、低头看手里的东西、抬头看天、回头看、闭着眼、看着身边的小动物、从扇子上方露出眼睛看过来。

### 地点

- 家里：廊檐、榻榻米房间、窗边的矮桌、小厨房、玄关、浴室门口、屋顶、小院子、书架前、暖桌里
- 街上：旧书店、茶屋、澡堂门口、商店街、电车站台、天桥、自动售货机旁、夏日祭的摊位前、桥上、河堤
- 野外：竹林、梯田、茶山、海边、湖边的栈桥、向日葵田、芒草原、樱花树下、银杏道、雪地、山顶、溪边
- 不存在的地方：云上、月亮上、水面上、巨大的荷叶上、鱼缸里、书页里、茶杯边、星空里

### 四季的小东西

- 春：樱花、油菜花、紫藤、草莓、三色团子、燕子、风筝、新茶
- 夏：牵牛花、紫阳花、风铃、蚊香、西瓜、刨冰、金鱼、萤火虫、烟花、麦茶
- 秋：红叶、银杏、芒草、柿子、栗子、烤红薯、赏月团子、蜻蜓
- 冬：山茶、水仙、橘子、暖桌、围巾、热茶、雪兔子、年糕、门松

### 纸与笔触（插画线）

看得见水彩纸的颗粒、颜色边缘有水渍、远处用湿画法晕开、留出纸的白当高光、线稿有轻有重、局部只勾线不上色、画面四周自然淡出到纸色。

## 五、出图后对照检查

每张图拿到手，按这八条看一遍。前四条不过关就重画，后四条可以用第一节的话改。

1. 脸：是不是同一个人？圆润脸型、短平眉；插画线大而圆的深色眼睛，Q 版适中深褐眼、微小高光。
2. 头发：黑发、自然分缕的齐眉刘海和两鬓细卷；插画与 Q 版都是后脑低发髻。
3. 发饰：绿叶加小鱼，在不在？在不在对的那一侧？
4. 画法：和基准图是不是同一种画法？
5. 条纹：衣服上的条纹（或单张指定的那一处条纹）在不在？
6. 手：手指数对不对，姿势自然不自然？
7. 文字：有没有冒出不该有的字、水印、签名？
8. 画幅和留白：比例对不对，该留的空位留了没有，人有没有被裁掉？

## 六、容易踩的坑

- **一次要太多**：一句话里要求画四张、八张，人物会一张比一张走样。一条一张。
- **不传参考图**：只靠文字，每次出来的都是另一个人。每个新对话都要先传图。
- **对话拖太长**：同一个对话里画了二三十张以后，前面的设定会被淡忘。觉得不对劲就新开对话。
- **让它写字**：中文字经常写错。需要文字的地方让它留空，自己后加。
- **改的时候说得太笼统**：「不好看，重画」没有用。说清楚哪里不对、要改成什么样、其余不要动。
- **左右弄反**：提示词里的「左」「右」，说人物身上的部位时指人物自己的左右，说画面时指看画的人的左右。发饰在人物自己的左侧，正面看就是画面右侧，背面看就是画面左侧。
