# 41 · 系列：周边物料（14 张）

- 画风线：实物效果图（周边上印的图案用插画线或 Q 版线）｜画幅：方形 1:1（1024×1024）｜一条提示词出一张
- 特点：看看这个形象做成东西是什么样子。每张是一件周边的效果图，像网店的商品主图。可以拿去和厂家沟通，也可以直接当宣传图。
- 用法：上传两条线的基准图、设定图，最好再上传几张已经生成的满意作品 → 先发「系列总提示词」→ 再逐条发「单张提示词」。

## 系列总提示词

```text
接下来我会分 14 次给你描述，每次只画一张周边商品的效果图。所有图都要遵守下面的设定，直到我说「系列结束」。现在先不要画，只回复「明白」。
【本系列】《周边物料》：每张是一件实物商品的效果图，像网店的商品主图——干净的摄影棚光线，柔和的阴影，商品是真实的材质（亚克力、金属、纸、布、陶瓷、毛绒），拍得清楚、好看。
【商品上印的图案】图案里的人物是我上传的参考图里的那个形象，分两种画法，单张会写明用哪一种：
「插画图案」——
【角色锁定｜必须与参考图是同一个人】二十岁左右的年轻女子。圆润的鹅蛋脸，脸颊饱满、带淡粉色红晕；眼睛大而圆、深褐近黑、眼神沉静；细而平的短眉；小巧的鼻子只用淡淡一笔；小嘴、淡粉唇色；皮肤白皙偏暖。乌黑微卷的短发，齐眉薄刘海带碎发，两鬓垂下几缕细卷发，脑后挽一个松松的低发髻。人物脸型、发型和服装以 02 号三视图为准；鱼饰始终逐形复刻原始 i-kimono.jpg，04 号图仅作复刻细节辅助。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝，带两三片深绿色尖刺叶；枝头的金灰褐色烤鱼头饰必须逐形复刻 `参考图/原始素材/i-kimono.jpg`，`参考图/原始素材/a-portrait.jpg` 仅补充角度：保留原图鱼头与很短前段的轮廓、微张的嘴、眼睛、鳃盖、色斑及枝叶遮挡关系，后部与枝叶连接。不另设身体或尾部比例，不擅补大圆腹、扇尾或突出的背鳍。`IP形象图像/00-角色基准/04-设定图-发型与发饰细节.png` 仅作复刻细节辅助。单张提示词没有另写时，发饰保持不变。
画法是日系水彩插画，细腻的深褐色线稿，淡彩，低饱和的大地色。穿暖米色与炭灰褐相间的宽条纹浴衣。
「Q 版图案」——
【角色锁定｜必须与参考图是同一个形象】从插画角色重新设计的约 2.7 头身水彩 Q 版女子，身份以基准版 06 号 Q 版设定图为准。圆润的小鹅蛋脸、柔粉腮红、暖白肤色；适中大小的深褐色眼睛，只有微小高光，眼神安静温和；细短眉、小鼻子和小嘴。乌黑微卷的短发，自然分缕的碎齐刘海，两鬓几缕细卷发，后脑一个松松的低发髻。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝，带两三片深绿色尖刺叶；枝头的金灰褐色烤鱼头饰必须逐形复刻 `参考图/原始素材/i-kimono.jpg`，`参考图/原始素材/a-portrait.jpg` 仅补充角度：保留原图鱼头与很短前段的轮廓、微张的嘴、眼睛、鳃盖、色斑及枝叶遮挡关系，后部与枝叶连接。不另设身体或尾部比例，不擅补大圆腹、扇尾或突出的背鳍。`IP形象图像/00-角色基准/04-设定图-发型与发饰细节.png` 仅作复刻细节辅助。单张提示词没有另写时，发饰保持不变。
画法是水彩 Q 版，细深褐线、柔和水彩晕染和纸张颗粒，低饱和暖色。穿暖米与炭灰褐宽条纹浴衣、墨绿腰带；身份以基准版 06 为准。
【要求】图案在商品上要印得端正、完整、清晰，是整张效果图的主角；人物的脸不能因为商品的弧度而变形得认不出。商品和包装上不要出现任何文字、商标、条形码。
【背景】暖米色或浅灰色的纯色背景，可以有一两件很简单的陪衬小物，由单张指定。
【画幅】方形 1:1，商品居中，占画面六到七成。
```

## 单张提示词

### 41-01 亚克力立牌
一块透明亚克力的人形立牌，插在一块圆形的透明底座上。图案：Q 版图案，全身，挥手微笑；图案沿着小人的轮廓切割，外面留一圈透明的边。亚克力的边缘有透亮的反光，底座上印着几片小叶子。陪衬：旁边一只真实的茶杯，用来对比大小。

### 41-02 徽章一套
六枚圆形的马口铁徽章，排成两行三列，平放。图案：Q 版图案的六个大头表情——微笑、大笑、惊讶、生气鼓脸、困、害羞；每枚的底色不同，都是低饱和的淡色（米、淡绿、淡粉、淡蓝、淡黄、淡紫）。徽章表面有一层光亮的覆膜，边缘有金属的卷边。

### 41-03 钥匙扣
一只亚克力钥匙扣，带金色的金属圆环和一小段链子。图案：只有她的记号——两片深绿色的小叶子和原图金灰褐鱼饰的复刻造型，Q 版画法，沿轮廓切割；链子上还挂着一枚小小的 Q 版大头吊牌。钥匙扣斜放在一块亚麻布上。

### 41-04 贴纸一张
一整张 A5 大小的贴纸，上面有十几枚模切好的小贴纸：Q 版图案的各种动作和表情、三花猫、小金鱼缸、小麻雀、茶杯、团扇、叶子小鱼记号。每枚贴纸有白边，之间留着间距；贴纸纸张是哑光的，其中一枚的一角被微微揭起，露出底纸。平放俯拍。

### 41-05 纸胶带
三卷和纸胶带立着摆成一排，各拉出一小段平铺在前面。第一卷的花纹：暖米色与炭灰褐相间的宽条纹上，隔一段有一条小鱼。第二卷：淡青绿色底上，连续排列的 Q 版小人，每个动作不同。第三卷：米白色底上，散点的小叶子和小鱼。能看出和纸半透明的质感。

### 41-06 明信片套装
五张明信片呈扇形摊开，最上面一张完整露出，下面几张露出一部分；旁边是装它们的牛皮纸封套，封套上用一条条纹纸腰封扎着。图案：插画图案，五张分别是春、夏、秋、冬四季的她，和一张她的标准半身像。明信片是有纹理的水彩纸质感，四周留白边。

### 41-07 帆布包
一只本白色的帆布托特包，挂在一只木衣架上。包的正面印着：插画图案，她的半身像，只用深褐色单色线条印刷，只有发饰的叶子印了绿色。包的提手内侧是条纹布。包口露出一本书和一枝花。帆布有清晰的织纹和自然的褶皱。

### 41-08 马克杯
一只米白色的陶瓷马克杯，哑光釉，杯身略有手工感。杯身正面印着：Q 版图案，她双手捧着茶杯喝茶；杯子的内壁靠近杯口处印着一条小小的金黄色小鱼，喝到一半才会看见。杯里是热茶，冒着一点热气。陪衬：一只小木托盘，一块点心。

### 41-09 手机壳
一只手机壳，背面朝上平放，旁边斜放着另一只不同款的。第一只：淡青绿色底，插画图案的她站在右下角，左上方留空，散着几片叶子。第二只：整面是暖米色与炭灰褐的宽条纹，只在一角有一枚 Q 版大头。手机壳是磨砂质感，摄像头的开孔位置空出来，不要挡住图案里的脸。

### 41-10 桌垫
一张横长的大号桌垫铺在木头桌面上，上面压着一只键盘的一角和一只鼠标。图案：插画图案，一幅横向的风景——画面右侧是坐在廊檐上的她，左侧三分之二是安静的院子和傍晚的天空（放键盘的地方没有细节）。桌垫边缘有一圈细密的锁边，表面是细布纹。俯视偏斜的角度。

### 41-11 毛绒玩偶
一只二十厘米高的毛绒玩偶，坐姿，按 Q 版的样子做的：圆圆的大头，黑色的绒布头发和后脑低发髻，刺绣的眼睛和腮红，头上缝着两片绿色的毛毡叶子和一枚按原图鱼饰轮廓制作的金灰褐绒布鱼饰；身上是条纹布做的小和服。面料是短绒，看得见缝线。它靠在一只枕头上，旁边放着同款的小号挂件。

### 41-12 T 恤
一件米白色的短袖 T 恤，平铺在浅色木地板上，袖子自然摊开。胸口左侧印着一枚小小的图案：叶子和小鱼的记号。背面的图案用一件对折的同款露出一部分来表示：一幅较大的插画图案，她的背影和回眸。面料是厚实的棉，领口有罗纹。陪衬：一顶草帽。

### 41-13 台历
一本立在桌上的台历，三角形的支架，上方是金属线圈。翻开的这一页：上半部分是插画图案的当月主题画（她在雨天的廊檐下看紫阳花），下半部分是月历的格子——格子里不要写数字和文字，只画出空的网格，其中一格里有一枚小鱼的小印记。旁边一支笔、一盆小小的绿植。

### 41-14 礼盒全家福
一只打开的方形礼盒，米色的硬纸盒，盒盖斜靠在后面，盒盖上印着条纹和叶子小鱼的记号。盒子里用碎纸丝垫着，整整齐齐地放着：亚克力立牌、一枚徽章、钥匙扣、一卷纸胶带、几张明信片、马克杯、毛绒小挂件。盒子外面用一条墨绿色的丝带扎了一半。俯视四十五度，光线温暖。这一张把前面的周边放在一起，各件的样子要和前面画的一致。

## 扩展：只要印刷用的平面图

效果图满意之后，要拿去制作，还需要不带实物的平面图案：

```text
请把刚才第 N 张商品上印的图案单独给我：不要商品、不要阴影、不要透视，正面平视，透明背景，图案完整，四周留出一圈空白，尺寸尽量大。
```

## 收尾

```text
系列结束。请把刚才 14 张按编号顺序排成一张总览图（三行，每行 5 张，最后一行居中），间距一致，背景用暖米色，不写字。
```
