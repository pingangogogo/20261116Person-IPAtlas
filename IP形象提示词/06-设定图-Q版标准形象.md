# 06 · 设定图：Q 版标准形象（单张）

- 对应：1 张图｜画风线：Q 版线｜画幅：横版 3:2（1536×1024）
- 作用：重新设计 Q 版的「三视图 + 基本表情 + 基本动作」。以后所有 Q 版系列以 `IP形象图像/00-角色基准/06-设定图-Q版标准形象.png` 为身份基准。
- 用法：上传用户认可的 `IP形象图像/00-角色基准/06-设定图-Q版标准形象.png` 保持 Q 版人形；鱼饰另上传原始 i-kimono.jpg、a-portrait.jpg 和角色基准版 04，仅修正鱼饰 → 粘贴下面整段。

## 提示词

```text
请从我上传的插画角色重新设计一张约 2.7 头身的水彩 Q 版形象设定图；已有基准版 06 时以它保持身份。
【角色锁定｜必须与参考图是同一个形象】从插画角色重新设计的约 2.7 头身水彩 Q 版女子，身份以基准版 06 号 Q 版设定图为准。圆润的小鹅蛋脸、柔粉腮红、暖白肤色；适中大小的深褐色眼睛，只有微小高光，眼神安静温和；细短眉、小鼻子和小嘴。乌黑微卷的短发，自然分缕的碎齐刘海，两鬓几缕细卷发，后脑一个松松的低发髻。
【标志发饰】人物左耳上方（正面看在画面右侧）斜插一根柊树小枝，带两三片深绿色尖刺叶；枝头的金灰褐色烤鱼头饰必须逐形复刻 `参考图/原始素材/i-kimono.jpg`，`参考图/原始素材/a-portrait.jpg` 仅补充角度：保留原图鱼头与很短前段的轮廓、微张的嘴、眼睛、鳃盖、色斑及枝叶遮挡关系，后部与枝叶连接。不另设身体或尾部比例，不擅补大圆腹、扇尾或突出的背鳍。`IP形象图像/00-角色基准/04-设定图-发型与发饰细节.png` 仅作复刻细节辅助。单张提示词没有另写时，发饰保持不变。
【画风】水彩 Q 版：细而有轻重的深褐色线条，柔和水彩晕染与纸张颗粒，低饱和暖色；轮廓自然，不加贴纸白边。背景透明，单张另写时以单张为准，做不到透明则用纯白。
【禁止】不要改变圆润脸型、自然碎齐刘海和后脑低发髻；不要放大眼睛或高光；不要矢量粗线、渐变光泽、3D 或金属质感；不要高饱和荧光色；除单张指定的符号外不要出现文字和水印；肢体不要被画面边缘裁掉。
【第一排：角度】同一个 Q 版小人的全身站姿四个：正面、四分之三侧面、正侧面、背面。等高、脚底对齐。背面画清楚后脑低发髻、叶子和原图复刻鱼饰的位置。
【第二排：表情】六个大头特写：平静（圆眼）、开心（眼睛笑成两道弯弧）、惊讶（眼睛变成两个小圆圈、嘴张圆）、生气（眉毛倒八字、鼓腮）、委屈（眼角下垂、一颗泪）、困（眼睛眯成两道横线、头顶一个小泡泡）。
【第三排：动作】六个全身小动作：挥手、双手捧着冒热气的茶杯、抱着笔记本电脑、坐着打盹、双手举高欢呼、蹲着看地上的金鱼缸。
【服装】暖米色与炭灰褐相间的宽条纹浴衣，白色半襟，墨绿色腰带；手脚是简化的圆形。
【统一规格】每个小人的脸型、约 2.7 头身比例、细深褐线条和水彩颗粒一致；不加贴纸白边或投影。整张图底色用很浅的暖灰纸色（#EFE8DD），不透明。不要任何文字和编号。
【画幅】横版 3:2。
```

## 验收要点

- 刘海是否自然分缕、两鬓有细卷，后脑是否为低发髻。
- 发饰是否位于人物自己的左侧，并逐形复刻原始 i-kimono.jpg 的轮廓、嘴眼鳃盖、色斑与枝叶遮挡关系。
- 是否为约 2.7 头身、圆润小鹅蛋脸、适中深褐眼；细线水彩，不加贴纸白边。
